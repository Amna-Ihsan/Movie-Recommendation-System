#  Movie Recommendation System

## Overview

This project is a **content-based movie recommendation system** that recommends movies similar to a movie selected by the user. It uses movie titles to identify similar content and provides the top 5 recommendations through an interactive Streamlit web application.

##  Live Demo

* **Streamlit App:** [https://movie-recommendation-system-lxckgspvmevzw3jgdzndub.streamlit.app/]

## Project Features

* Recommends the top 5 similar movies
* Displays movie posters
* Displays movie ratings
* Interactive movie search
* User-friendly Streamlit interface
* Handles missing movie data


## Libraries & Technologies

* **Python** – Programming language
* **Pandas** – Data loading and preprocessing
* **NumPy** – Numerical operations
* **Scikit-learn** – Machine learning and text processing
* **TF-IDF Vectorizer** – Text feature extraction
* **Cosine Similarity** – Measuring similarity between movies
* **Streamlit** – Web application and user interface
* **Requests** – Downloading recommendation data
* **Pickle** – Saving and loading processed data
* **Hugging Face** – Hosting processed movie data
